# 🌍 Global Fashion Retail Analytics Dashboard

> **End-to-End Data Analytics Capstone Project** using **MySQL, Power
> BI, Excel, and SQL**.

## Project Overview

This project analyzes a global fashion retail dataset to uncover
insights about sales performance, customer behavior, product categories,
promotions, and geographic trends.

The workflow includes: - Data Cleaning & Preparation - SQL Business
Analysis (10 Questions) - Power BI Interactive Dashboard (5 Pages) -
Business Recommendations

------------------------------------------------------------------------

## Tools Used

  Tool       Purpose
  ---------- -----------------------------
  MySQL      Data Storage & SQL Analysis
  Power BI   Interactive Dashboards
  Excel      Initial Data Cleaning
  SQL        Business Queries
  DAX        Measures & KPIs

------------------------------------------------------------------------

## Dataset

### Tables Used

  Table          Description
  -------------- ----------------------
  Customers      Customer information
  Products       Product details
  Stores         Store information
  Employees      Employee data
  Transactions   Sales & Returns
  Discounts      Promotion details
  Calendar       Date intelligence

------------------------------------------------------------------------

## SQL Business Questions

-   Customer demographics by country and city
-   Returns percentage and monthly trend
-   Top categories by revenue
-   Payment method analysis
-   Discount vs non-discount sales
-   New vs repeat customers
-   Store performance
-   Price band analysis
-   Basket analysis by country
-   Month-over-month revenue growth
